# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-09-16

Fresh start as Gymfreek. No history carried over.

### Added

- Public landing page with new volt identity, display font, animated stats,
  3D workout card and movement marquee.
- Full onboarding training profile: date of birth, health conditions, injuries,
  experience level, goals.
- Generic challenge system: Challenge, ChallengeDay, ChallengeTask (loads, cues,
  demo-video slots), Enrollment, Payment.
- Real 100XU century seed: 100 days, 1,000 tasks across 10 blocks.
- Razorpay Test Mode: create-order, HMAC verify, idempotent webhook.
- Admin panel: challenges, enrollments, users, day editor API.
- AI service skeleton in the Gymfreek-ai repo with the contracted endpoints.
